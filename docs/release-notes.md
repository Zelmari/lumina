Apple silicon · macOS 15.2 or later

Download the Lumina ZIP, extract it, move Lumina.app into Applications, and open it. Lumina runs in the menu bar without a Dock icon. Config is available from the menu or Control–Option–Space. Launch at Login is optional.

This release is ad-hoc signed and is not notarized by Apple. If macOS blocks launch, open System Settings → Privacy & Security and use Open Anyway if you trust the download. Grant Accessibility to **Lumina Agent** when prompted.

Quit Lumina using **Quit all** before replacing an existing installation. Configuration stays in `~/.config/lumina/lumina.toml`.

`SHA256SUMS` contains the archive checksum. `lumina.rb` is the corresponding Homebrew cask for the maintainer's tap.
